1. Open the folder in a new Terminal Shell by right-clicking on an empty space of the window and selecting the voice "Open in Terminal"
2. Run "cd data-generator"
3. Run "make"
4. Run "cd bin" to access the directory of the data-generator program
5. Run "./data-generator" to load the sleep data generator
6. Follow the instructions to generate the data
7. Repeat operation 3 and 4 if you want to generate the data for the whole month
8. Now you can find the CSV file needed in the data directory
9. Run "cd ../../somni" to acess Somni's directory
10. In case npm isn't already installed on you system, run "sudo apt install npm" and insert your password
12. Run "npm install"
13. If the Terminal show a warning message indicating a moderate vulnerability, fix it by running "npm audit fix"
14. Run "npm run dev" to launch the dev local server
15. Open your browser (Chrome or Firefox for a better experience), then copy and paste in the search field the link provided by Vite in the previous step
16. Enjoy
